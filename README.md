# PSY 512 · Visual Cognition · presentations

Two interactive paper presentations for PSY 412/512 (Sabancı University, Fall 2026).

- `imagery/` · Pearson (2019), *The human imagination* · [PDF](imagery/pearson-2019-human-imagination.pdf)
- `eye-tracking/` · Shvarts & Abrahamson (2019), *Dual-eye-tracking Vygotsky* · [PDF](eye-tracking/shvarts-abrahamson-2019-dual-eye-tracking.pdf)

Keys: ← → or Space to move, N speaker notes, F full screen.
Run locally: `python -m http.server 8512`, then open http://localhost:8512.

Figures are redrawn as interactive schematics; none are reproduced from the papers.
